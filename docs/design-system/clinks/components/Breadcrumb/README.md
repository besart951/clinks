# Breadcrumb

The path to the current page as quiet links.

## Markup

```svelte
import * as Breadcrumb from '@codelinks/ui/components/breadcrumb';
```

## Rules

- In the staff apps prefer a PageHeader `back` link; the shell already shows the context.
- Text `caption` in `muted-foreground`; the current page in `foreground`.
