# Flags

Rounded-rectangle flag icons (32 × 32 viewBox, 4px corners, a subtle darker outline). Copied from `packages/ui-core/src/lib/components/svg/flags`. The language select shows them at 20px with 2px corners beside the language name.

| File | Language | In use |
| --- | --- | --- |
| `switzerland.svg` | Deutsch (Schweiz), `de-CH`, the primary language | Language select |
| `england.svg` | English, `en` | Language select |
| `france.svg` | Français | Present in the package, not offered yet |
| `italy.svg` | Italiano | Present in the package, not offered yet |
| `spain.svg` | Español | Present in the package, not offered yet |

Show a flag only beside the language's written name. In the open list the flag is decorative (`alt=""`); on the closed trigger it carries the language as its alt text. The colours are the flags' own and are not theme-aware.
