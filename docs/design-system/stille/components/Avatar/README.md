# Avatar

Steht für eine Person – Initialen auf `muted`, oder ein Foto, falls vorhanden.

## Markup
`<span class="ui-avatar">BA</span>` (32px) bzw. `ui-avatar--sm` (24px); mehrere in `ui-avatar-group`, max. drei plus „+n“.

## Regeln
- Keine zufälligen Farben pro Person – alle Initialen-Avatare gleich neutral.
- Der Name steht daneben oder im Tooltip; der Avatar allein identifiziert niemanden.

## shadcn/ui
`<Avatar>`, `<AvatarImage>`, `<AvatarFallback>`.
